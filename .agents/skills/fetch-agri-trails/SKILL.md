# Fetch Agri Trails Skill

## Overview
Collects verified agricultural hiking trails and rural scenic routes in Israel with strict zero-hallucination validation and $0 total cost.

## Authority Identifier
All assets generated by this skill carry an official `AGRI-TRAIL-XXX` authority identifier.

## Input Parameters
- `region_filter`: (Optional) `"all"`, `"north"`, `"center"`, `"jerusalem"`, `"south"`.

## Usage Example
```python
from skills.fetch_agri_trails import fetch_agri_trails

trails = fetch_agri_trails(region_filter="all")
print(f"Loaded {len(trails)} agricultural trails.")
```
