# Fetch IAA Antiquities Skill

## Overview
Collects verified public archaeological sites and historical fortresses in Israel with strict zero-hallucination validation and $0 total cost.

## Authority Identifier
All assets generated by this skill carry an official `IAA-SITE-XXX` authority identifier.

## Input Parameters
- `region_filter`: (Optional) `"all"`, `"north"`, `"center"`, `"jerusalem"`, `"south"`.

## Usage Example
```python
from skills.fetch_iaa_antiquities import fetch_iaa_antiquities

sites = fetch_iaa_antiquities(region_filter="all")
print(f"Loaded {len(sites)} antiquity sites.")
```
