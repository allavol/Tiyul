# Fetch Urban Nature Parks Skill

## Overview
Collects verified municipal and metropolitan urban nature parks in Israel with strict zero-hallucination validation and $0 total cost.

## Authority Identifier
All assets generated by this skill carry an official `MUNI-PARK-XXX` authority identifier.

## Input Parameters
- `region_filter`: (Optional) `"all"`, `"north"`, `"center"`, `"jerusalem"`, `"south"`.

## Usage Example
```python
from skills.fetch_urban_nature_parks import fetch_urban_nature_parks

parks = fetch_urban_nature_parks(region_filter="all")
print(f"Loaded {len(parks)} urban nature parks.")
```
