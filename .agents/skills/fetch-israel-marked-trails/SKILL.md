# Fetch Israel Marked Trails Skill

## Overview
Collects verified marked hiking trails in Israel with strict zero-hallucination validation and $0 total cost.

## Authority Identifier
All assets generated by this skill carry an official `ITC-TRAIL-XXX` authority identifier.

## Input Parameters
- `region_filter`: (Optional) `"all"`, `"north"`, `"center"`, `"jerusalem"`, `"south"`.

## Usage Example
```python
from skills.fetch_marked_trails import fetch_marked_trails

trails = fetch_marked_trails(region_filter="all")
print(f"Loaded {len(trails)} marked hiking trails.")
```
