Deep Dive — Task 7: Reason Chips Implementation

Exact implementation plan for _matchReasons in AgentRulesEngine.js

1
At the start of each candidate's score calculation in rankCandidates(), initialise const reasons = [].
2
After each scoring branch that fires, push a human-readable chip: e.g. if (a.stroller_accessible) { scoreA += 15; reasons.push('🚼 נגיש לעגלות'); }
3
Always push the age chip: reasons.push(`✅ גיל ${a.min_age}+`) when age is safe. Push '💧 נחל/מים' for water feature match, '🌲 יער מוצל' for shade match, '🏛️ עתיקות' for history, etc.
4
After sort, attach site._matchReasons = reasons.slice(0, 4) to each returned site object (cap at 4 chips).
5
In AgentChatBot.jsx, in the proposal card render: add a flex gap-1 flex-wrap mt-1.5 row of <span className="teal-chip"> chips from proposal._matchReasons. Conditionally render only when array is non-empty.
